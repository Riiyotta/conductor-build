# Design-repo: conductor.build clone

An AI-ready, machine-validated PageSpec system for a local React 18 + Vite 5 + Tailwind 3.4 + react-router-dom 6 replica of a real, live company site (Melty Labs / Conductor). It lets a generator compose new on-brand pages from closed token, section and template vocabularies without inventing colours, copy budgets, sections or assets.

**Status: `design-review-pending`, `productionApproved: false`.** Treat as a snapshot taken 2026-10-22 of a replica that can keep changing.

## Layout

```
registry.manifest.json   status, counts, versions (see versionFieldNote), entryPoints (inside this folder only)
tokens/00-foundation..30-layout, themes/light.json, llm/{token-catalog,token-policy,component-allowlist,motion-patterns}.json
primitives/ components/ sections/        one JSON contract per type, each with measuredFrom citations
templates/templates.json                 11 page shapes: structured nodes (required/repeatable), routes identical to ia.json
compatibility/graph.json                 13 rhythm/position rules, severity error|warn, named exceptions
assets/asset-roles.json                  closed asset-role contract with pinned compliance roles
schema/                                  pagespec.schema.json (draft-07, generated by build_schema.py), example, semantic_validate.py, tests/adversarial_test.py
extraction/                              measured-values.json (evidence + corrections + gaps), verify_all.py, prove_drift.py
```

## Run

```
python3 extraction/verify_all.py          # every check; exit 1 on any FAIL
python3 schema/tests/adversarial_test.py  # mutations must be rejected, controls must pass
python3 extraction/prove_drift.py         # injects drift into scratch copies and proves each check fails
python3 schema/semantic_validate.py schema/example.pagespec.json
```
Python 3 + `jsonschema` (draft-07) only. Scripts derive the repo root from `__file__`. Citation, `ia.json` and route checks need the sibling project tree and degrade to warnings when it is absent.

## Things deliberately not normalised away

- **Forms are local-only.** The enterprise and team-plan HubSpot forms in the clone never POST anywhere; the original posts to a live HubSpot portal. `form-endpoint` is pinned `must-not-reuse-live-endpoint`.
- **Downloads hit a live third-party CDN.** The dialog's Apple-silicon/Intel buttons point at the vendor CDN. `download-endpoint` is pinned the same way. The URLs and form/portal ids are intentionally not stored here.
- **Real company content.** Logos, team photos, avatars, testimonials, docs and changelog text, and the Conductor marks are real. Roles `brand-mark`, `customer-logo`, `vendor-mark`, `person-avatar`, `team-photo`, `product-screenshot` are pinned `must-not-reproduce`: placeholders or rights-holder-supplied assets only. Never fabricate testimonials, people, releases or legal text. The example uses placeholders for all of these.
- **Original quirks replicated:** homepage is 402px wide and brandkit 500px at 390px; team-plan form sits in a 450px clipping scroll box; pricing FAQ is static (not an accordion); privacy/terms section titles are bold paragraphs, not headings; the footer is sans on the homepage and mono on the other 305 routes.
- **404 is out of IA.** `src/pages/NotFound.jsx` (retro terminal) is not in the sitemap and is not one of the 306 routes (`templates.json` `specialRoutes`).
- **Delivery weight.** Docs/changelog media is about 1.14 GB (two videos of 735 MiB and 164 MiB). This repo contains none of it; never bundle it with a generated page.
- **Spec corrections.** Later audits corrected the written specs (fonts, motion, container padding, media max-height, footer placement, colours); `extraction/measured-values.json` lists each with evidence and prefers them over spec text.

## Packaging and git hygiene

Package with the CLI `zip` (excluding `.DS_Store`, `__MACOSX`, `__pycache__`), generated last, as a sibling `design-repo.zip`. Never put the zip inside `design-repo/` and never commit it: add `design-repo.zip` to the project's `.gitignore`. A `.gitignore` inside this folder covers caches.
