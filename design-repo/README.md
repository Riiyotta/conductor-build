# Design-repo: conductor.build clone

An AI-ready, machine-validated PageSpec system for a local React 18 + Vite 5 + Tailwind 3.4 + react-router-dom 6 replica of a real, live company site (Melty Labs / Conductor). It lets a generator compose new on-brand pages from closed token, section and template vocabularies without inventing colours, copy budgets, sections or assets.

**Status: `design-review-pending`, `productionApproved: false`.** Treat as a snapshot taken 2026-10-22 of a replica that can keep changing.

## Run

```
python3 extraction/verify_all.py          # every check; exit 1 on any FAIL
python3 schema/tests/adversarial_test.py  # mutations must be rejected, controls must pass
python3 extraction/prove_drift.py         # injects drift into scratch copies and proves each check fails
python3 schema/semantic_validate.py schema/example.pagespec.json
# re-measure section heights (needs a browser; see the header of the script): writes sectionHeights into measured-values.json
PLAYWRIGHT=/path/to/playwright/index.mjs node extraction/measure_sections.mjs --write
```
Python 3 + `jsonschema` (draft-07) only. Scripts derive the repo root from `__file__`. Citation, `ia.json` and route checks need the sibling project tree and degrade to warnings when it is absent.

## Section decomposition, provenance and the whole-page-wrapper gate

- **Sections are parts of a page, not pages.** Three contracts used to hold a whole page body (`changelog.post-entry` 2,824px of a 3,474px post page, `changelog.entry-list` 14,005px of a 14,587px index page, `content.legal-prose` 11,488px of the 12,070px `/privacy`). They are now `changelog.entry-header` (variants `index` and `post`: version badge, date, title) + `changelog.entry-body` (the markdown body, `mustFollow` its header, repeated per article on the index), and `content.legal-header` (title and date line) + `content.legal-body` (`mustFollow` its header). There is no table of contents on the legal pages and no related/prev-next block on a post, so none is modelled; the back link and the index pager were already their own sections. Template ids and route counts are unchanged (306 routes mapped exactly once: 207 post, 21 index, 69 docs).
- **`content.prose-article` stays one body, deliberately.** The page header is already `hero.page-header`, and the render shows no distinct header or footer part inside the article. Measured per node at 1440px it is 28px on `/enterprise` (the earlier ~1,280px figure was the article wrapper, which also holds the logo grid and HubSpot form, now their own nodes), 887px (26%) on `/join-us` and 1,249px (63%) on `/slack`, which is whitelisted below.
- **Provenance is separate from taxonomy.** Each contract has `semantic` {semanticId, category, iaSections} (what the section means in the IA) and `source` {sourceId, implementedBy, measuredFrom} (the replica file it was read from, with citations). Both are closed by `schema/section-contract.schema.json`; `semanticId` must equal the contract id, `sourceId` must be one of the files cited in `implementedBy`, and verify_all checks category and implementing file against `ia.json`.
- **`retrievalEligible`.** A closed boolean on every contract. `false` for the dialogs, drawers and overlays that are not design compositions (`shell.download-dialog`, `shell.downloading-screen`, `docs.mobile-drawer`, `docs.search-dialog`), `true` elsewhere. It is const-locked per section in the PageSpec schema (optional on a node, default true), listed in the allowlist as `retrievalIneligibleSections`, and pinned independently in code (`semantic_validate.RETRIEVAL_INELIGIBLE`); verify_all fails if the code pin, the contracts, the allowlist and the schema disagree.
- **Whole-page-wrapper gate** (`verify_all.py` check `wrapper-gate`, thresholds pinned in code). Against the 1440px section heights recorded in `extraction/measured-values.json` for all 306 routes: a HERO-category section over 1800px warns and over 3000px fails; any single section instance holding over 50% of its page warns and over 60% fails. Only a reviewed `wrapperGate.whitelist` entry (justification, caps, restricted to sections pinned as prose by nature in `verify_all.PROSE_BY_NATURE`, and reported stale if nothing needs it) suppresses it. Current whitelist: `content.legal-body` (96% of `/terms`), `docs.prose-body` (94%), `changelog.entry-body` on a post (91%), `content.prose-article` on `/slack` (63%), `content.pricing-faq` (55%). The sticky sidebar and TOC columns (`docs.sidebar`, `docs.toc`) sit beside the article and are exempt from the share rule only. Heights are border-box extents of each node's DOM range, measured on the built clone; the method is in the header of `extraction/measure_sections.mjs`.
- **Not measured here:** there is no live-site capture in this environment, so no visual-parity number is recorded or claimed.

## Things deliberately not normalised away

- **Forms are local-only.** The enterprise and team-plan HubSpot forms in the clone never POST anywhere; the original posts to a live HubSpot portal. `form-endpoint` is pinned `must-not-reuse-live-endpoint`.
- **Downloads hit a live third-party CDN.** The dialog's Apple-silicon/Intel buttons point at the vendor CDN. `download-endpoint` is pinned the same way. The URLs and form/portal ids are intentionally not stored here.
- **Real company content.** Logos, team photos, avatars, testimonials, docs and changelog text, and the Conductor marks are real. Roles `brand-mark`, `customer-logo`, `vendor-mark`, `person-avatar`, `team-photo`, `product-screenshot` are pinned `must-not-reproduce`: placeholders or rights-holder-supplied assets only. Never fabricate testimonials, people, releases or legal text. The example uses placeholders for all of these.
- **Original quirks replicated:** homepage is 402px wide and brandkit 500px at 390px; team-plan form sits in a 450px clipping scroll box; pricing FAQ is static (not an accordion); privacy/terms section titles are bold paragraphs, not headings; the footer is sans on the homepage and mono on the other 305 routes.
- **404 is out of IA.** `src/pages/NotFound.jsx` (retro terminal) is not in the sitemap and is not one of the 306 routes (`templates.json` `specialRoutes`).
- **Delivery weight.** Docs/changelog media is about 1.14 GB (two videos of 735 MiB and 164 MiB). This repo contains none of it; never bundle it with a generated page.
- **Spec corrections.** Later audits corrected the written specs (fonts, motion, container padding, media max-height, footer placement, colours); `extraction/measured-values.json` lists each with evidence and prefers them over spec text.

## Packaging and git hygiene

Package with the CLI `zip` (excluding `.DS_Store`, `__MACOSX`, `__pycache__`), generated last, as a sibling `design-repo.zip`. Never put the zip inside `design-repo/` and never commit it: add `design-repo.zip` to the project's `.gitignore`. A `.gitignore` inside this folder covers caches.
