# Changelog

## 0.3.0 - 2026-10-24 (design-review-pending)

Generation-safe revision: reference vs generated PageSpec mode (PageSpec-breaking, `pageSpecVersion` 2.0.0).

counts: tokens=213 primitives=11 components=18 sectionContracts=42 iaSections=46 templates=11 routes=306 graphRules=13 assetRoles=23 adversarialMutations=212 adversarialControls=30

A generator composing a page for another brand had no way to say "this is not Conductor" and nothing checked that it was not: the asset roles (`brand-mark`, `product-screenshot`, ...) were the source's own, and the source's name, CTA labels, marketing copy and URLs were all valid PageSpec content.

- **`mode` (required closed enum `reference` | `generated`)** on every PageSpec (schema generated by `build_schema.py`, allowlist `pageSpecTopLevelProperties`, all four existing examples now `mode: reference`). A PageSpec without it is invalid, so `pageSpecVersion` is 2.0.0 (manifest `repositoryVersion` 0.3.0). `reference` = documents the source: source copy and the roles observed on it are allowed. `generated` = a new page for a different brand.
- **Asset roles** (`assets/asset-roles.json`, 12 -> 23 roles): every role has a closed `availability` (`reference-only`, `generation-safe`, `blocked-for-generation`), `generatedModeGuidance`, and (for the first and last) `generationSafeSubstitutes`. Reference-only: `brand-mark`, `product-screenshot`, `demo-video`, `decorative-background`, `ui-animation`. Blocked: `customer-logo`, `vendor-mark`, `person-avatar`, `team-photo`, `form-endpoint`, `download-endpoint`. Generation-safe: `icon` plus 11 new roles: `brand-placeholder`, `customer-logo-placeholder`, `avatar-placeholder`, `screenshot-placeholder`, `video-placeholder`, `background-generated`, `animation-generated`, `endpoint-placeholder` and the content rules `fictional-brand`, `original-copy`, `placeholder-url`. New policy `placeholder-endpoint-only`. Availability is pinned in code twice (`semantic_validate.PINNED_AVAILABILITY` and an independent `PINNED_AVAILABILITY` in `verify_all.py`), so flipping a role in the registry to a different-but-valid value is caught.
- **Section contracts**: every media/endpoint field has `generatedRoles` (disjoint from `roles`, each a substitute of a field role) and 17 sections carry the derived `generatedAssetRoles`; the PageSpec schema accepts the union and the semantic layer picks the set by mode.
- **`sourceBrand.patterns`** (34 patterns, 5 categories: brand, cta, copy, url, asset), every pattern derived from literals found in `src/` and carrying `file:line` evidence, the real strings it must match (`mustMatch`) and a benign list it must not match. Brand: `conductor` (any compound), Melty / Melty Labs / Melty, Inc. / meltylabs / melty.sh, the bundle id. CTA: `Get|Try|Download|Join Conductor`, `Download for Mac`, `Download for Intel-based Macs`, `Join Windows/Linux waitlist`, brand-kit titles. Copy: home hero/feature/closing-CTA copy, the six real testimonial quotes and authors, team member names, pricing bullets, Join Us and brand-kit prose, changelog titles and summaries, a docs description, a privacy sentence. URLs: conductor.build and subdomains, the notion/tigris/storage buckets, the CDN, HubSpot portal and form ids, the Google Form, Discord/X/YouTube/Reddit, real people's post URLs, GitHub uploads. Assets: the clone's asset tree, protected file names, testimonial photos.
- **Validator** (`schema/semantic_validate.py`), mode `generated` only: `GENERATED_MODE_REFERENCE_ASSET` (reference-only or blocked role), `GENERATED_MODE_ROLE` (not one of the field's generation-safe roles), `GENERATED_MODE_SOURCE_BRAND`, `_SOURCE_CTA`, `_SOURCE_COPY`, `_SOURCE_URL`, `_PROTECTED_ASSET` (strings in text, URL, pattern, alt and route fields, after NFKC / zero-width / quote / whitespace normalisation), `GENERATED_MODE_URL_HOST` (absolute URLs only on `*.example`, `*.invalid`, example.com/org/net), `ASSET_AVAILABILITY_DRIFT`, `GENERATED_MODE_PATTERNS_MISSING` (an empty pattern category fails closed). Reference mode still validates the source's real content; a generation-safe role in a reference page is `ASSET_ROLE`.
- **Examples**: `schema/examples/generated.template.{home,legal,changelog-post,docs-page}.pagespec.json` (fictional brand "Fernlake", original copy, placeholder roles, URLs on `.example`).
- **Tests**: adversarial suite 212 mutations and 30 controls (brand-name, CTA, copy, URL and protected-asset leakage, role and mode cases, repo-level registry edits, every reference example flipped to generated; controls: the generated examples, the reference examples, and a generated plus a reference control per template). `verify_all.py` new checks `mode-schema`, `asset-availability`, `source-brand-patterns`, `generated-examples`, `adversarial-suite`; `prove_drift.py` 97 cases (49 before, 48 new) including the registry pins, generatedRoles, example leaks, pattern removal / loosening / widening, and "the validator stops enforcing generated mode".
- **Honest limits.** No human reviewed the pinned patterns: they are model-derived from `src/`, exact-text/regex matching only. A paraphrase, translation or homoglyph spelling of source copy passes; the substring `conductor` (also the English word) is blocked on purpose; source changelog slugs and docs paths that do not name the brand are not pinned; `Download for Mac` is pinned as a source CTA though another Mac app could use it. A PageSpec carries roles, not files, so a renderer is still responsible for what it draws for a role. Reference-mode pages keep the source's real strings (nothing blocks them there) and `extraction/measured-values.json` still contains source text as evidence.

## 0.2.0 - 2026-10-22 (design-review-pending)

Review revision: whole-page wrapper sections decomposed, utility retrieval flag, provenance/taxonomy split, quality gate.

counts at 0.2.0: tokens=213 primitives=11 components=18 sectionContracts=42 iaSections=46 templates=11 routes=306 graphRules=13 assetRoles=12 adversarialMutations=95 adversarialControls=15

- Split `changelog.post-entry` and `changelog.entry-list` into `changelog.entry-header` (variants `index`, `post`) + `changelog.entry-body`; split `content.legal-prose` into `content.legal-header` + `content.legal-body`. Templates, `ia.json`, `IA.md`, `matrix.csv`, compatibility graph (MUST_FOLLOW text, NO_ADJACENT exception for legal), allowlist, schema and examples updated together; template ids and the 306-route mapping (207 post, 21 index, 69 docs, 2 legal) are unchanged. The template matcher no longer reports a required repeatable node as missing once it was matched (needed for the repeating header/body pairs on the index).
- `content.prose-article` kept as one body with the justification and measured numbers in its contract and in `measured-values.json` (`prose-article-enterprise-wrapper-height`).
- `retrievalEligible` (closed boolean, false for the four overlay/dialog sections): contracts, schema (const per section, optional node property), allowlist `retrievalIneligibleSections`, code pin `RETRIEVAL_INELIGIBLE`, `retrieval-eligibility` check.
- Contracts now carry separate closed `semantic` {semanticId, category, iaSections} and `source` {sourceId, implementedBy, measuredFrom} objects (`schema/section-contract.schema.json`, `validate_contract`, `contract-shape` check, ia.json category/implementing-file parity). Feature-shell and HubSpot-form contracts now also cite the per-feature and form component files that `ia.json` names.
- Whole-page-wrapper gate (`wrapper-gate`): section heights for all 306 routes measured at 1440px (`extraction/measure_sections.mjs`, ledger in `measured-values.json`), HERO >1800px warn / >3000px fail, any section >50% of its page warn / >60% fail, reviewed prose-by-nature whitelist with caps and stale detection.
- Three new example PageSpecs (legal, changelog-post, changelog-index); adversarial suite 95 mutations (decomposition, contract shape, retrieval pins) and 15 controls; `prove_drift.py` 49 cases including the gate (hero 3500px, original post-wrapper bug, whitelist removed/stale/over cap, dropped node or route, loosened thresholds, warn cases).
- Not done: the visual-parity gate cannot be measured here (no live-site capture available).

## 0.1.0 - 2026-10-22 (design-review-pending)

- Tokens: foundation (colour, typography, radius, spacing, breakpoint, elevation, icon size, motion), semantic, component, layout, light theme, and the LLM layer (catalog, policy, allowlist, motion patterns).

- Adversarial suite and `verify_all.py` drift checks: allowlist parity, allowlistVersion, schema regeneration, token catalog/alias/theme recompute, motion parity, graph-vs-validator parity, asset-role pins, manifest and README/CHANGELOG counts, citation range AND quoted content, ia.json and route parity, stack re-diff, no absolute paths. `prove_drift.py` proves each fails on injected drift.
- Spec corrections recorded in `extraction/measured-values.json`.
